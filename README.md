# Workout Analytics Backend

A Spring Boot REST API for a workout tracking application that manages users, workouts, exercises, and exercise sets. This project is focused on backend development, relational data modeling, authentication, and SQL practice through native queries.

## Tech Stack
- Java
- Spring Boot
- Spring Security
- SQL Server / SSMS
- JPA / Hibernate
- Lombok
- JUnit
- Mockito

## Current Features
- User authentication with Spring Security
- REST API structure for backend communication
- 4-layer data model:
  - Users
  - Workouts
  - Exercises
  - Exercise Sets
- Persistent workout data storage with SQL Server
- Native SQL queries for hands-on database practice
- Unit testing with JUnit and Mockito

## Project Goal
The goal of this project is to build a backend system capable of storing and organizing workout data while also supporting future analytics such as workout history, exercise progression, and performance trends.

## Status
This project is currently in active development. Core backend structure, authentication, database integration, and testing are in place, with analytics features planned next.
